# Diamond Fountain Works Design

Use the established DFW identity while adapting the composition to the requested output. Read [references/design-system.md](references/design-system.md) for palette, typography and asset provenance. For an opening animation or a website handoff, also read [references/motion.md](references/motion.md).

## Preserve the identity

- Lead with saturated cobalt blue, cyan/green and near-black blurred forms, restrained grain, large compositions and room around the content.
- Keep text crisp. Blur belongs in atmosphere layers. Favor continuous contours and light silver finishes over dark metallic bands, cut-through speed lines and stacked outlines.
- Reuse [assets/diamond-wordmark.svg](assets/diamond-wordmark.svg) for the fixed brand name. It is outlined artwork, not text typeset in the Afterglow font. Preserve the supplied custom star from [assets/dfw-star.svg](assets/dfw-star.svg).
- Use Anton for condensed section/project headings and Nunito for readable body copy. For newly typed angular display lettering, start with DFW Afterglow Solid; use the incision-heavy display variant where size and legibility support it. See the reference for exact files and licenses.
- Write website content in English unless the user requests another language. Prefer factual project descriptions and current implementation status over promotional slogans.
- Treat One Kiss, Dashstar, Knock2, Apple, GTA VI and Ferrari as references for visual qualities and rhythm. Do not claim an original font has been identified or that a reference's assets/animation have been reproduced.

## Work from the latest state

Inspect the current artifact and assets before editing. Preserve newer user decisions over this snapshot or intermediate drafts. The accepted website sequence is: star flare → three-line title unfold → completed title moves into its actual hero position → background and other content appear. Keep the title visible and avoid an ending zoom. Detailed timing is a starting point, not a universal constraint.

For this particular portfolio, use the user-selected local projects and preserve the Blender exclusion. Recheck project facts when revising their descriptions. Do not extend that content restriction to unrelated DFW work.

## Make the result readable and continuous

Check the wordmark at both intended large size and compact size. If it is hard to read, simplify surface contrast and overlapping ornaments before adding effects or substituting the whole type system. Keep the intro and final wordmark on shared geometry and matching finishes; measure the real destination rather than hard-coding a visual approximation.

Respect the task's medium: SVG/HTML/CSS/vector work for scalable marks and motion; supplied desktop/web fonts for editable type. A font file provides contours; metallic rendering is a separate treatment.

## Deliver

Return the requested artifact and identify which brand assets and font version were used. Distinguish asset-rendering checks, motion-logic checks, browser/device inspection and publication evidence. Do not label an offline choreography preview as a browser recording or assume an old ZIP is the latest site.

This skill supplies design guidance and portable assets. It does not itself install fonts, choose a hosting account or authorize publication; follow the user's current task and the applicable platform workflow.
